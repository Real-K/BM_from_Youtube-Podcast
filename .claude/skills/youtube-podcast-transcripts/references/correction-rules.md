# 교정 규칙 — 누가 무엇을 하는가

| | 스크립트 (`correct_transcript.py`) | Claude (`corrections.jsonl`) | 아무도 안 한다 |
|---|---|---|---|
| 롤링 중복 제거 | ✔ | | |
| 태그·잡음 제거, 문단화, MM:SS | ✔ | | |
| 비율 검산 (`pct_mismatch`) | 표시 + 계산값 | 절대값 쪽으로 교정, basis=arithmetic | 비율만 있는 수치 교정 |
| 인접 값 충돌 (`adjacent_conflict`) | 표시 | 병기. 고르지 않음 | 한쪽 선택 |
| 숫자·단위 깨짐 (`number_unit_broken`) | 표시 | 같은 영상에서 단위 설명이 있으면 교정(context) | 단위 추정 복원 |
| 철자 군집 (`spelling_cluster`) | 표시 | 제목·설명·공개 정보로 확인되면 교정(external) | 그럴듯한 이름 선택 |
| 한 줄 내 반복 (`intra_repeat`) | 표시 | 그대로 둔다 | 반복 제거 |
| 진행자 삽입 (`host_insert`) | 표시 | 그대로 둔다, 인용 시 `[…]` | 삭제 |
| 공백·절단 (`gap`·`truncated`) | 표시 | 그대로 둔다 | 문장 이어 붙이기 |
| 부정어·의미 반전 | — | 앞뒤 논리로 후보 표시, medium 이하 | 문맥만으로 high 교정 |
| 화자 귀속 | — | 문맥 추정 → `추정`/`미확인` | 자막만으로 성명 확정 |
| 벤더 대변·재인용 | — | `speaker_role`·`reciting` 표시 | 도입 조직 발언으로 계상 |

## 근거의 종류와 허용 확신도

| basis | 뜻 | 최대 confidence |
|---|---|---|
| `arithmetic` | 절대값·연도가 있어 계산으로 확인 | high |
| `external` | 제목·설명란·채널·공개된 인물/제품/기관명으로 확인 | high |
| `context` | 같은 영상 안의 다른 발언(단위 설명, 반복 언급) | medium |
| `none` | 의심만 있음 | **교정 금지** — `[sic]` |

## 교정 표기

`corrected.md`에서 교정 자리는 `⟦원문 → 교정 (basis)⟧`. 근거 없는 의심은 `⟦원문 [sic]⟧`.
원문은 항상 남고, 교정본만 읽는 사람도 무엇이 바뀌었는지 안다.
